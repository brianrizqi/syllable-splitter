Tentang Aplikasi

Indonesian Syllable Splitter adalah aplikasi web untuk memisahkan kata bahasa Indonesia menjadi suku-suku kata dengan berbagai metode. Aplikasi ini dilengkapi dengan deteksi typo otomatis menggunakan database KBBI (112,643 kata) dan mendukung batch processing melalui upload CSV.

✅ 3 Metode Pemisahan

PUEBI, SylBI, dan KBBI Online untuk berbagai kebutuhan

🔍 Deteksi Typo

Validasi otomatis dengan 112,643 kata dari KBBI

🌐 Deteksi Bahasa

Identifikasi kata non-Indonesia secara otomatis

📊 Batch Processing

Upload CSV untuk memproses banyak kata sekaligus

Cara Menggunakan

📝 Tab: Masukkan Teks (Manual Input)

  1. Ketik atau paste teks di area input
  2. Pilih metode pemisahan (PUEBI/SylBI/KBBI)
  3. Aktifkan "Cek Ejaan" jika ingin deteksi typo
  4. Klik "Pisahkan Suku Kata"
  5. Hasil akan ditampilkan di bawah
Contoh:
Input: pembelajaran Indonesia
Metode: SylBI
Output: pe-m-be-l-a-jar-an In-do-ne-si-a

📄 Tab: Upload CSV (Batch Processing)

  1. Klik "Download Template CSV" untuk mendapatkan format
  2. Isi template dengan kata-kata yang ingin diproses
  3. Upload file CSV (drag & drop atau browse)
  4. Tunggu proses selesai (progress bar akan muncul)
  5. Lihat hasil di tabel
  6. Klik "Export Results" untuk download hasil
Format CSV Template:
word,method
pembelajaran,sylbi
Indonesia,puebi
membaca,sylbi

Metode Pemisahan Suku Kata

1. PUEBI (Pedoman Umum Ejaan Bahasa Indonesia)

Metode resmi dari Kemendikbud berdasarkan aturan pemenggalan kata PUEBI. Cocok untuk keperluan ejaan umum.

Contoh: pembelajaran → pem-be-la-ja-ran

2. SylBI (Syllabification for Bahasa Indonesia)

Metode hybrid yang menggabungkan analisis morfologi dengan pemisahan suku kata. Memisahkan awalan, sisipan, kata dasar, dan akhiran. Cocok untuk analisis linguistik.

Contoh: pembelajaran → pe-m-be-l-a-jar-an
(pe + m + be + l + ajar + an)

3. KBBI Scraper (Online Dictionary)

Mengambil pemisahan suku kata langsung dari KBBI Online. Memerlukan koneksi internet. Fallback ke PUEBI jika kata tidak ditemukan.

Aspek PUEBI SylBI KBBI
Fokus Fonetik Morfologi + Fonetik Referensi Resmi
Analisis Imbuhan Tidak Ya Tidak
Internet Tidak Perlu Tidak Perlu Perlu
Kecepatan Sangat Cepat Cepat Sedang

Deteksi Typo & Validasi KBBI

Aplikasi menggunakan 112,643 kata dari KBBI untuk validasi dan memberikan 3 jenis peringatan:

🔴 Kemungkinan Typo

Deteksi pola salah eja seperti:

  • Konsonan berlebihan (5+ konsonan berurutan)
  • Karakter berulang (3+ karakter sama berurutan)
  • Tidak ada vokal dalam kata panjang
Contoh: pmbljrn → Saran: pembelajaran

🟡 Tidak Ditemukan di KBBI

Kata tidak ada dalam database KBBI. Sistem akan memberikan saran kata yang mirip menggunakan edit distance algorithm.

Contoh: komputr → Saran: komputer, komputasi

🔵 Bukan Bahasa Indonesia

Deteksi kata asing berdasarkan:

  • Common English words (computer, learning, hello, dll)
  • Pola bahasa Inggris (-tion, -ing, th-, ght)
  • Huruf jarang dalam bahasa Indonesia (q, x, f)
Contoh: computer → Terdeteksi sebagai kata bahasa Inggris

API Endpoints

POST /split

Memisahkan teks menjadi suku kata

Request:
{
"text": "pembelajaran",
"method": "sylbi"
}

Response:
{
"results": [{
"word": "pembelajaran",
"syllables": ["pe","m","be","l","a","jar","an"]
}],
"method": "sylbi"
}

POST /check_spelling

Memeriksa ejaan dan memberikan suggestions

GET /download-template

Download template CSV untuk batch processing

POST /upload-csv

Upload dan proses file CSV

POST /export-results

Export hasil batch processing sebagai CSV

Tips & Tricks

  • Gunakan PUEBI untuk keperluan ejaan umum dan kecepatan maksimal
  • Gunakan SylBI untuk analisis linguistik dan riset morfologi
  • Gunakan KBBI untuk validasi dengan sumber resmi
  • Aktifkan Cek Ejaan untuk memastikan kata yang diinput benar
  • Batch Processing sangat berguna untuk memproses ratusan kata sekaligus
  • Export Results untuk menyimpan hasil dan analisis lebih lanjut
