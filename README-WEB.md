# 🎯 Syllable Splitter - Web Version

Aplikasi web untuk memisahkan kata menjadi suku kata dalam bahasa Indonesia.

## 🚀 Cara Menjalankan

**TIDAK PERLU INSTALL PYTHON!** Cukup buka file HTML di browser.

### Langkah-langkah:

1. **Buka file `index.html`** dengan salah satu cara berikut:
   - **Double-click** file `index.html` di Finder
   - **Klik kanan** → Open With → Browser pilihan Anda (Chrome, Safari, Firefox, dll)
   - **Drag & drop** file `index.html` ke jendela browser

2. **Mulai gunakan aplikasi!**
   - Ketik kata atau kalimat di kotak input
   - Klik tombol "Pisahkan Suku Kata" atau tekan Enter
   - Lihat hasil pemisahan suku kata
   - Klik tombol "Salin" untuk copy hasil

## ✨ Fitur

- ✅ **Tidak perlu install apapun** - Langsung jalan di browser
- ✅ **Desain modern & cantik** - Dark theme dengan animasi smooth
- ✅ **Responsive** - Bisa digunakan di HP, tablet, atau komputer
- ✅ **Contoh cepat** - Klik chip contoh untuk langsung coba
- ✅ **Copy hasil** - Salin hasil dengan satu klik
- ✅ **Algoritma akurat** - Menggunakan pola konsonan-vokal bahasa Indonesia
